# fastMathJax 1.0.0 — 侵入模式 + 完整稳定契约

## 0. 目标

新增**侵入模式**(默认关闭):开启后插件直接接管 Obsidian 原生 MathJax 的渲染入口,使所有渲染面(Reading View、Live Preview、hover 预览、嵌入、PDF 导出、popout 窗口)全部由插件的 MathJax 4.1.3 渲染 —— 自动闭环当前 fail-closed 的面(hover 预览、嵌入),并根除双引擎并存导致的样式冲突 bug 类(0.3.0 根因)。同时完成 ROADMAP 已定义的 1.0.0 stable contract 全部六项(API-01、LIFE-01、UPG-01、QA-01、DOC-02、REL-03)。

## 1. 可行性 Spike 结论(已完成,2026-09-07,本机 Obsidian 1.13.7 asar 逆向验证)

1. 原生 MathJax 为 **3.2.2**(`tex-chtml-full.js`,CHTML 输出、全扩展),首次数学渲染时才懒加载;注入脚本前的 `before` 钩子会**无条件覆写** `window.MathJax` 配置 → "预写配置"路线不可行,**加载后打补丁是唯一稳妥路线**。
2. 所有渲染调用点都是**运行时全局动态查找**:公开 API `renderMath(src, display)` 的实现就是 `MathJax.tex2chtml(src, {display})`;样式同步调 `MathJax.chtmlStylesheet()`。Reading 内部 post-processor(处理 `.math:not(.is-loaded)`)与 Live Preview 的 CM6 widget 两条管线全部汇入这两个口 → **patch 这两个成员 = 全量接管**,hover/嵌入/PDF 自动覆盖。
3. `loadMathJax()` 是公开 API,插件 `await loadMathJax()` 后打补丁时机安全,且懒加载意味着插件通常先加载。
4. 原生管线约定:返回单个 `mjx-container` 根元素。MathJax 4 输出同一标签词汇表,天然兼容(需关闭 0.3.0 引入的 `latest-mjx-*` 标签改名隔离,因为侵入模式下全页只有一套词汇表)。
5. 复验方式:`grep -a -b -o -E "MathJax\.tex2chtml|chtmlStylesheet" "%APPDATA%\obsidian\obsidian-<版本>.asar"`;运行时不依赖版本号,靠特性守卫。

## 2. 设计

### 2.0 启用前警告确认弹窗(本次新增要求)
- 设置里把侵入模式开关打开时**不立即生效**:先弹出确认 `Modal`(标题"启用侵入模式?"),内容分两栏:
  - **收益**:全部渲染面统一升级到 MathJax 4.1.3(Reading、Live Preview、hover 预览、嵌入、PDF 导出、popout);单一引擎,根除双 MathJax 样式冲突类问题;完整宏/preamble 能力覆盖所有渲染面。
  - **风险**:依赖 Obsidian 内部实现,Obsidian 更新可能使其失效(届时自动回退非侵入模式并提示);与直接依赖原生 MathJax 3 渲染行为的第三方插件可能表现不一致;实验性功能,默认不开启。
- 按钮:"启用侵入模式"(confirm 类样式)/ "取消"。确认 → 保存并热切换;取消 → 开关回退、不保存、不切换。
- 仅在**打开**时弹窗;关闭不弹。两套设置 UI(1.13 声明式 `onChange` + 1.8–1.12 命令式)统一调用同一确认逻辑(单一 `confirmInvasiveEnable(): Promise<boolean>`),`src/invasive/InvasiveConfirmModal.ts` 实现。
- 测试:确认 → 设置保存且 bridge 安装;取消 → 设置不变、无 install;只有开→开方向触发;UI 两路径共用。

### 2.1 设置(默认关闭)
- `invasiveMode: boolean = false`;UI 名"侵入模式(实验性)"。两套设置 UI 同步添加。
- 开启时各渲染面开关(Reading/LP/行内等)置灰并注明由侵入模式统一接管;preamble/宏/字体/renderer/缓存等引擎设置继续生效。
- **热切换**:确认后 → `saveSettings` → bridge install/uninstall + `refreshRenderedSurfaces`,无需重启。设置迁移测试:旧 `data.json` 无此键 → false。

### 2.2 新模块 `src/invasive/`
- `NativeMathBridge.ts`:`install()`(await loadMathJax → 特性守卫 `tex2chtml && chtmlStylesheet` 均为函数 → 保存原成员 → patch)、`uninstall()`(恢复原成员,幂等)。守卫失败 → Notice + 返回 false,main.ts 自动落回现有非侵入 adapters,不阻塞加载。
- 渲染 facade(tex2chtml 替身),签名 `(tex, {display?}) => HTMLElement`:
  - 复用现有引擎全部能力:configHash 缓存键 + LRU 模板克隆缓存、revision 戳、preamble 宏、assistive MML 开关。
  - 同步返回单个 mjx-container 根;**不做** `latest-mjx-*` 改名;保留 `data-latest-mathjax-engine/revision` 戳。
  - 错误按现有 `fallbackMode`(obsidian/raw/error)映射;空 TeX 返回空容器(对齐 v3 行为)。
  - **同步 flush 样式**(flush 机制新增 sync 选项,保留 0.4.0 的 200ms 定时器兜底),防 hover 弹层无样式闪现。
  - `chtmlStylesheet()` 替身:返回引擎持久 style 元素(id 稳定、replace-don't-append 已有),使 Obsidian 的样式同步保持幂等。
  - **打印路由**:调用时检测 `.print` 上下文 → 改用 pdfEngine(SVG,沿用 0.1.3 决策),规避打印窗口 webfont 竞态;M1 实测,不通过则备选 CHTML + 0.5.0 本地字体缓存。
- 样式同步微 post-processor:侵入模式下唯一保留的 post-processor,**不渲染**,只做 per-document `ensureStyles`(popout 样式复制),复用 CompatibilityManager 的 document 身份判定。

### 2.3 引擎改动
- `EngineConfig.isolationEnabled = true`(默认不变,非侵入零变化);侵入模式置 false → `isolateOutput` 标签改名(MathJaxEngine.ts:313)与 `isolateStyles` 选择器重写(:458)被跳过。`outputIsolation.ts` 保留服务非侵入模式。

### 2.4 生命周期
- 启动:onLayoutReady → engine ready → invasiveMode 且 install 成功 → 不注册渲染 adapters;失败 → 现行为。
- 卸载:onunload → `bridge.uninstall()` 恢复原成员 → 刷新重建原生输出(LIFE-01 门禁:无残留补丁/样式/监听器)。
- 引擎重建(preamble/renderer/packages 变更):revision 递增 + 表面刷新,复用 0.4.0 机制。

## 3. 里程碑

- **M1 — PoC**:临时最小实现(patch tex2chtml 直通引擎),测试库手动验证 Reading / Live Preview / hover / PDF 四面渲染与样式正确;验证打印路由。退出标准:四面全过,缺口结论记入文档。
- **M2 — 产品化**:上述 2.x 全量实现(含确认弹窗);新增约 30 个测试:bridge(装/卸幂等、守卫失败降级)、facade(缓存克隆、revision 戳、错误映射、空 TeX、display、打印路由、chtmlStylesheet 幂等)、引擎 isolationEnabled 双态、设置迁移与热切换、确认弹窗逻辑、LIFE-01(unload 后 `window.MathJax` 成员 === 原引用、无 style/observer 残留)。第一时间验证 eslint `obsidianmd/no-unsupported-api` 是否拦 window 补丁;若拦,仅对 `src/invasive/` 豁免并注明理由。
- **M3 — 桌面验收 + 基准**:完整矩阵(CHTML+SVG × Reading/LP 块+行内/hover/嵌入/popout/PDF);开→关→开循环(含弹窗确认/取消两路径)、插件禁用重启、冷启动(侵入默认开)、失效注入(删 tex2chtml → 降级);`__bench` 双模式跑分(100/500 笔记,warm/cold/scroll/typing/sanity)记入 docs/benchmarks.md,对比 0.5.0 基线(预期:不再有 settle 等待与整节扫描,typing 延迟下降;回归需解释)。
- **M4 — stable contract + 发布**:API-01(设置语义冻结文档)、LIFE-01、UPG-01(0.4→1.0、0.5→1.0、clean install、损坏 data.json 归一化)、QA-01(两轮 RC 验收)、DOC-02 与框架修订(README"隔离保证"改为"默认隔离 + 显式 opt-in 侵入(带启用确认弹窗)";dev-plan.zh.md §2.1 追加 1.0 决议;ROADMAP 增 INV-01..07 并修订 packaging decision rule 例外条款;compatibility.md 支持矩阵重写;STATUS、CHANGELOG)、REL-03(`npm run check` → `release: publish 1.0.0` → tag `1.0.0` → CI 资产/provenance 验证 → 0.5.0 回滚演练)。

## 4. 风险与对策
- **Obsidian 更新改变内部** → 运行时特性守卫 + 自动降级非侵入 + Notice;补丁面最小(2 个成员);不硬编码版本号。
- **发布 lint 门禁** → M2 首项验证;只做目录级豁免并注明理由,不全局关规则。
- **MathJax 4/3 视觉差异**(行高、度量、空公式)→ styles.css 增加 `body[data-latest-mathjax-invasive]` 作用域补偿规则;M1 集中暴露。
- **其他插件依赖 v3 独有 API**(tex2svg 等)→ 不 patch,原生保留,文档注明。
- **原生 MathJax 仍会加载**(1.3MB 懒加载)→ 接受;阻止加载的 setter-trap 路线脆弱,列 backlog。
- **与创立原则冲突**(README 隔离保证、ROADMAP packaging rule)→ 文档显式修订;"安全回退 + 可完全清理"两条架构约束保留不谈判。
- **用户误开启** → 启用前强制确认弹窗(收益/风险双栏),取消即回退。

## 5. 明确不做
- 移动端:保持 `isDesktopOnly: true`(manifest 守卫测试不动,MOB-01 另列)。
- 不删除非侵入 adapters(降级依赖)。
- 不 patch `renderMath`/`finishRenderMath` 本体与 `tex2svg`。
- Canvas 维持不支持(COMP-02 结论不变)。
